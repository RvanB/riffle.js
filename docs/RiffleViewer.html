RiffleViewer

RiffleViewer

Description:

  • A Riffle viewer.

    A viewer is a DOM element (a <canvas>) with the viewer API mixed in. Create it with createViewer, append it to the document, then call these methods directly on it — there is no separate controller object or mounting step. Riffle imposes no wrapper element or layout styling; you decide how the element is positioned, scrolled, and decorated.
